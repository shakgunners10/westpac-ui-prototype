# Westpac UI Prototype

An interactive HTML/CSS/JavaScript recreation of the Westpac banking website, built for Assessment 2 (Design a UI Prototype).

**Note:** This is a student educational project only. It is not affiliated with or endorsed by Westpac Banking Corporation, and is not intended for any commercial or public-facing use.

## Pages

- Homepage (`index.html`)
- Login (`login.html`)
- Personal Banking (`personal-banking.html`)
- Business Banking (`business-banking.html`)
- Contact Us (`contact.html`)

Each page is responsive across desktop, tablet, and mobile breakpoints, matching the Figma wireframes produced for this assessment.

## Tech stack

- HTML5
- CSS3 (custom / Bootstrap — update once decided)
- Vanilla JavaScript
